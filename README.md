# Radar das Câmaras

Jurisprudência dos Tribunais de Contas sobre a gestão das câmaras municipais.

- `data/decisoes.json` — acervo (uma entrada por decisão)
- `build.py` — gera o site estático em `dist/` (`python3 build.py`)
- `assets/style.css` — estilo
- `dist/` — site pronto, publicado pelo Cloudflare Pages (diretório de saída: `dist`, sem comando de build)
